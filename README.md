# Virtual-Thread Cascading Backpressure

Research artifact for studying stability boundaries and adaptive admission control in Java virtual-thread services under finite downstream capacity.

## Working paper title
**Stability Boundaries and Adaptive Admission Control for Java Virtual-Thread Services Under Downstream Resource Saturation**

## Research question
At what concurrency-to-downstream-capacity ratios does a Java virtual-thread service transition from stable operation into cascading queue, memory, GC, latency, timeout, and error amplification, and can adaptive admission control prevent or delay that transition?

## Artifact scope
- prior-art record and search log
- Java virtual-thread service and downstream bottleneck
- reproducible load-generation and telemetry
- baseline and adaptive admission-control mechanisms
- raw/processed benchmark data
- analysis scripts and paper figures
- IEEE manuscript sources
